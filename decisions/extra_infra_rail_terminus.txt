# Rail terminus -> extra_infra
#
# Every rail terminus of level N gives +1 extra_infra to its own province and to every
# province within N provinces of it, counting adjacency steps. The range only runs
# through provinces the terminus' controller controls, so it stops at the border.
# Termini stack: a province in range of three termini gets +3.
#
# OMG recalculates the whole map once a week: every extra_infra level is stripped, then
# handed out again terminus by terminus. Nothing smaller would do - a province changing
# hands changes what it should have, and script cannot remember who controlled it.
#
# Script has no loops and no province variables, so each terminus is walked with nested
# any_neighbor_province scopes, one nesting level per province of distance, and the
# rings are kept apart with province flags:
#   ring k   - from the terminus, walk only through provinces flagged ring 1 .. k-1 and
#              flag every neighbour not yet seen as ring k. That is an exact
#              breadth-first distance, so a province is never counted twice or too far.
#   apply    - walk ring 1 .. N again, giving +1 and clearing the flags on the way in, so
#              a province reached by two paths only gets it from the first one.
# The flags are gone again before the next terminus is handled. The country being
# walked carries the flag extra_infra_walker, which is how a province deep in the walk
# can ask whether it is controlled by the terminus' country.
#
# Generated - one block per terminus level, because the nesting depth is the level.
