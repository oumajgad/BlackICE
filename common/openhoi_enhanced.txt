# This file turns on OpenHOI3's enhanced mode for the mod.
#
# The original game never reads it: it only opens the files under common/ that
# it asks for by name. OpenHOI3 looks for exactly this file, and its being here
# - even empty - makes every game played from this mod an enhanced one: the
# engine then mends the faults of the original it has fixes for, and the mod's
# Lua finds OpenHOI3.Enhanced set to true.
#
# Every fix is on unless it is named here as one the mod does not want:
#
#     without = { minister_tech_decay simplified_terrain_sea }
#
# The fixes, by name:
#
#   minister_tech_decay      a minister's technology decay modifier counts, where
#                            the original throws it away. BiceLib:
#                            BytePatches.fixMinisterTechDecay
#   simplified_terrain_sea   the Simplified Terrain map mode colours the sea by
#                            its terrain, as it does the land. BiceLib:
#                            BytePatches.seaTerrainColourInSimplifiedMapMode
#   offmap_ic                a country-level "ic" modifier counts as off-map IC:
#                            a country's IC is its provinces' sum and that
#                            figure, where the original never reads it.
#   fresh_screens            screens the original writes once and then leaves
#                            are kept up to date: the province view, the
#                            technology panel, a diplomacy row's threat, name
#                            and flag, the list of trades, and a fleet's list of
#                            what it carries. Display only.
#   menu_resumes             closing the in-game menu starts the clock again
#                            where the menu stopped it, also after Save Game,
#                            Game Options or Message Settings was opened.
#   tooltips_on_screen       a tooltip is kept from leaving the screen at the
#                            left and the top too. Display only.
#   shown_figures            figures shown a hundred times too small or too
#                            large are shown as they are: a terrain's or a
#                            circumstance's attrition on the brigade card and in
#                            the division designer, a fleet's positioning
#                            penalty in the reorganise window, a production
#                            slider with nothing needed (100% covered), and a
#                            fleet's hourly organisation regain at sea.
#                            Display only.
#   unit_ordinals            a new unit's number takes the ending of its last
#                            two digits: 111th, 112th, 113th, where the original
#                            writes 111st, 112nd, 113rd. Changes the names of
#                            units made from then on.
#   air_orders_for_all       with several air units selected, the orders window
#                            greys a mission that any of them may not fly, as it
#                            does for several fleets; the original offers the
#                            first unit's missions and hands them to all.
#   key_without_equals       in a province's history and a unit file, a key with
#                            no "=" takes the word after it: "manpower 0.66" is
#                            manpower 0.66, where the original gives the key the
#                            value of the pair before it and loses the word.
#   unit_figure_decimals     a unit figure of more than three decimals is cut to
#                            three, in a unit's file and a technology's block
#                            for a unit type: 0.3375 is 0.337, where the
#                            original reads 3.375.
#   yield_modifiers          a province's yield of fuel is scaled by its
#                            holder's global_fuel and of money by global_money;
#                            the original has the two the wrong way round.
#
# Six more give a value the original loads and never uses a meaning. The
# original has no rule for any of them, so each rule is OpenHOI3's own:
#
#   tech_repair_cost         a technology's repair_cost_multiplier for a unit
#                            type is added with its other figures; the original
#                            leaves it out of the sum.
#   trait_dissent_impact     a leader's dissent_impact scales what dissent costs
#                            his unit at sea, in the air and under bombs, as it
#                            does on land.
#   raid_trait_hours         a raid on a convoy, by sea or from the air, counts
#                            the hours the raider's leader banked in it towards
#                            his traits, so a trait that wants a convoy battle
#                            (seawolf) can be earned by raiding.
#   trait_fort_defence       a unit defending behind a whole level of fort - of
#                            coastal fort where an attacker comes from the sea -
#                            has its leaders' fort_defence on its attack and
#                            defence. The original reaches the trait only for an
#                            attacker, where it does nothing.
#   radar_efficiency         a radar station's reach is longer by its country's
#                            radar_efficiency: reach x (1 + radar_efficiency).
#   trait_surprise_chance    the side that picks its combat tactic second rolls
#                            its highest ranked leader's surprise_chance: under
#                            it, and where it may pick that tactic at all, it
#                            takes the tactic that counters the other side's
#                            outright. One roll more, only for a side with the
#                            trait.
#
# Six more are fixes BiceLib has on the original, each under the name given:
#
#   historical_model_choice  a historical model that asks for a level above the
#                            one held loses to every model that does not, so a
#                            country is not shown a model it has not
#                            researched. Display only. BiceLib:
#                            BytePatches.historicalModelLogicFix
#   queued_historical_model  a queued brigade's historical_model gives a level
#                            for every technology of its type, 0 for one the
#                            model does not name, so no level lands on the
#                            technology before it. BiceLib:
#                            ComplexPatches.fixQueuedHistoricalModel
#   place_unresearched_building
#                            a finished building waiting to be placed may go
#                            where its country has not researched it; every
#                            other test of the placing stands, and ordering one
#                            still asks for the technology. BiceLib:
#                            ComplexPatches.enablePlacingNonResearchedBuildings
#   oob_leader_ranks         a land leader a file of units puts on a land unit
#                            of his own country takes the rank of that unit's
#                            level and is put in service. BiceLib:
#                            Leaders.activateOobLeaderRanks
#   history_leader_ranks     a leader put in service on the day his history
#                            first gives him a rank takes the rank that line
#                            names, 1 to 4, where the original gives rank 1.
#                            BiceLib: Leaders.activateHistoryLeaderRanks
#   saved_event_candidates   a save keeps each country's candidate events, so a
#                            loaded game fires events from its first day, where
#                            the original's fires none until its month turns.
#                            BiceLib: Events.rebuildCandidates
#   air_regroup_agrees       the AI joins a small air group to another only
#                            where its own splitting rule would not take a
#                            wing out again. The original's joining rule knows
#                            its own eight air types alone, so the mod's light
#                            bombers and flying boats were joined and split
#                            again for the whole game. Nothing of BiceLib's.
#
# Two more are of the interface:
#
#   ctrl_unassign_selected   with Ctrl held, agreeing to the leader window's
#                            "remove all leaders" takes the leaders off the
#                            selected units alone, and off nobody where none of
#                            them has one. BiceLib:
#                            Leaders.activateCtrlUnassignSelected
#   tooltip_scroll           a tooltip taller than the screen shows as many
#                            lines as fit and is moved through with Alt and the
#                            wheel, or Alt and the Up or Down key. Any tooltip.
#                            BiceLib: EffectTexts.activateTriggerScroll, which
#                            scrolls a requirement's alone.
#
# The lines the engine writes that the original does not - a leader's highest skill, what a load_oob file
# would do, a unit's figures and damage in a battle, the designer's paradrop and combined arms lines - are
# switched on by their texts being in localisation/openhoi/texts.csv, and are no fixes.
#
# Rules that are the mod's choice are not named here - they are data where their subject is, in
# common/defines.lua: how many units a command may hold (OPENHOI_..._UNIT_LIMIT, with the unit_limit_ entries
# that end common/triggered_modifiers.txt), whether the AI lends its units (OPENHOI_AI_LENDS_UNITS) and whether
# war exhaustion is handed to neutrality at peace (OPENHOI_WAR_EXHAUSTION_TO_NEUTRALITY)
# (docs/openhoi/README.md, "Rules that are the mod's choice").
#
# Anything else written here is reported in OpenHOI3's log and ignored.
# Saves of an enhanced game are kept apart, in "save games/openhoi".
