# This file turns on OpenHOI3's enhanced mode for the mod.
#
# The original game never reads it: it only opens the files under common/ that
# it asks for by name. OpenHOI3 looks for exactly this file, and its being here
# - even empty - makes every game played from this mod an enhanced one: the
# engine then mends the faults of the original it has fixes for, and the mod's
# Lua finds OpenHOI3.Enhanced set to true.
#
# Every fix is on unless it is named here as one the mod does not want:
#
#     without = { minister_tech_decay simplified_terrain_sea }
#
# The fixes, by name:
#
#   minister_tech_decay      a minister's technology decay modifier counts, where
#                            the original throws it away. BiceLib:
#                            BytePatches.fixMinisterTechDecay
#   simplified_terrain_sea   the Simplified Terrain map mode colours the sea by
#                            its terrain, as it does the land. BiceLib:
#                            BytePatches.seaTerrainColourInSimplifiedMapMode
#   offmap_ic                a country-level "ic" modifier counts as off-map IC:
#                            a country's IC is its provinces' sum and that
#                            figure, where the original never reads it.
#   fresh_screens            screens the original writes once and then leaves
#                            are kept up to date: the province view, the
#                            technology panel, a diplomacy row's threat, name
#                            and flag, the list of trades, and a fleet's list of
#                            what it carries. Display only.
#   menu_resumes             closing the in-game menu starts the clock again
#                            where the menu stopped it, also after Save Game,
#                            Game Options or Message Settings was opened.
#   tooltips_on_screen       a tooltip is kept from leaving the screen at the
#                            left and the top too. Display only.
#   shown_figures            figures shown a hundred times too small or too
#                            large are shown as they are: a terrain's or a
#                            circumstance's attrition on the brigade card and in
#                            the division designer, a fleet's positioning
#                            penalty in the reorganise window, a production
#                            slider with nothing needed (100% covered), and a
#                            fleet's hourly organisation regain at sea.
#                            Display only.
#   unit_ordinals            a new unit's number takes the ending of its last
#                            two digits: 111th, 112th, 113th, where the original
#                            writes 111st, 112nd, 113rd. Changes the names of
#                            units made from then on.
#   air_orders_for_all       with several air units selected, the orders window
#                            greys a mission that any of them may not fly, as it
#                            does for several fleets; the original offers the
#                            first unit's missions and hands them to all.
#
# Anything else written here is reported in OpenHOI3's log and ignored.
# Saves of an enhanced game are kept apart, in "save games/openhoi".
